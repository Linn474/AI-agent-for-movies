# ИИ-агент
## Помощник по просмотру фильмов/сериалов
### Возможности *(Данный список описывает долгосрочные планы по развитию агента. На текущем этапе (ЛР №2) реализован базовый функционал: добавление, просмотр полного списка фильмов и смена статуса на "Просмотрено".)*
* Добавлять фильмы (сохранять название)
* Менять статус просмотра ("В планах", "Просмотрено", "Брошено", "Смотрю", "Любимое")
* Добавлять письменные комментарии и оценки
* Показывать фильмы по категориям (фильтрация по статусу просмотра)
### Предполагаемые примеры работы:
#### Запрос 1: 
* **Пользователь**: Добавь фильм "Реальные упыри" в список и поставь статус "Просмотрено"
* **Результат**: Агент добавляет фильм в список(`бд`) и меняет статус на "Просмотрено"
#### Запрос 2:
* **Пользователь**: Поставь сериалу "Кухня" 10/10 и добавь комментарий "Легенда"
* **Результат**: Агент добавляет комментарий с оценкой и текстом в базу
### Технологический стек:
* Язык программирования для разработки: `Python` (версия `3.11+`)
* Редактор: `Visual Studio Code` (`VS Code`)
* Менеджер зависимостей: `uv`
* База данных: `SQLite` (встроенная библиотека `sqlite3`)
* Библиотека для консольного вывода: `rich`
* Линтер и форматтер: `ruff`
* Отладчик: `Visual Studio Code` встроенный
### Подготовка окружения:
1. Установить `Python` (версию `3.11` или выше). Скачать можно с официального сайта `python.org`.
2. Установить менеджер пакетов `uv`. Инструкция по установке для Windows, macOS и Linux доступна на официальном сайте: `https://docs.astral.sh/uv/getting-started/installation/`. После установки перезапустите терминал, чтобы команда uv стала доступна
3. Открыть терминал (в Windows - PowerShell или командную строку; в macOS/Linux — стандартный терминал; либо встроенный терминал в вашей IDE, например, в `Visual Studio Code`: **Terminal -> New Terminal**).
4. Клонировать репозиторий и перейти в папку с проектом:
  * Введите: `git clone <ссылка_на_репозиторий>`
  * Введите `cd AI-agent-for-movies`
5. Установить зависимости с помощью команды `uv sync`
### Запуск:
Для запуска агента введите команду `uv run python -m src.ai_agent_for_movies`
### Команды приложения:
* *add* - добавить фильм в список.
* *list* - показать все фильмы с их ID и статусами.
* *done* - отметить фильм как просмотренный (по ID).
* *delete* - удалить фильм из списка (по ID).
* *help* - показать справку.
* *exit* - штатно завершить приложение.
### Способ хранения данных:
Состояние приложения (список фильмов) сохраняется в реляционной базе данных `SQLite`. При первом запуске программы в корне проекта автоматически создается файл `movies.db` и таблица `movies`. Благодаря этому данные не теряются после перезапуска приложения.
### Проверка качества кода:
В проекте настроены линтер и форматтер `ruff` (он уже есть в зависимостях, отдельно устанавливать не нужно).
* Запуск линтера (поиск ошибок): `uv run ruff check .`
* Автоисправление ошибок линтера: `uv run ruff check --fix .`
* Запуск форматтера (приведение к единому стилю): `uv run ruff format .`
